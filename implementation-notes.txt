打开方式
1. 在本文件所在目录执行：python3 -m http.server 8876 --bind 127.0.0.1
2. 访问 http://127.0.0.1:8876/compare.html 查看逐页对比与比例方案。
3. 访问 http://127.0.0.1:8876/ 查看可操作原型；右下角“预览”可选择 14 个页面 / 状态并重播。
4. 所有资源均在本包中，不需要安装前端依赖。

交付内容
- index.html / app.js / style.css：完整本地交互原型。
- compare.html / compare.js / compare.css：叠加拖动、并排与实时动效预览。
- comparison/before：线上 Unity WebGL 实际截图。
- comparison/after：本轮本地实现截图。
- design-tokens.json：1920×1080 的尺寸、字体、颜色、安全区参数与 DOM 实测值。
- motion-spec.json：逐页动效、缓动、时长、错峰与生命周期说明。

Unity 落地建议
- 用 1920×1080 作为 CanvasScaler 的参考分辨率。按当前工程策略保留 matchWidthOrHeight，先用横版实际设备核对，勿盲目整套缩放。
- 分别调整菜单、表单、卡片、字幕与弹窗组件的尺寸，字号与间距见 design-tokens.json。
- 用 RectTransform 包装层承载入场位移、缩放与 CanvasGroup alpha；控件本体保留 hover / press 反馈，避免两个动画同时写同一 transform。
- 统一页面退出 150ms，进入按 motion-spec.json 的时间错峰；背景保留更长的尾段，结束时保持相同基准姿态。
- 封面推近曲线的起止速度和加速度为零；结束后保持最终帧。不要在完成回调中跳回 100%。
- 场景和配置数据就绪后再播放入场。导航取消旧轨道和旧计时，确保重播、快速返回、暂停恢复不会叠加。
- 焦点、Esc、确认 / 取消、减少动态效果等状态与输入系统对接；保留真实游戏、章节、节点、存档 API。
- 本包没有伪造可直接导入的 Unity Prefab；需由实际 Unity 工程完成 UGUI / UI Toolkit 组件绑定并构建验证。

界面音效
本轮换为通透、轻盈的原创泛音与立体声空间混响，并混合新制素材层。风格参照见 sound-spec.json；原始提示词与素材来源见 ethereal-sound-sources.json。
九种声音为 48kHz 双声道 PCM WAV。Hover 1.05s、点击 1.35s、通用选择 0.48s、章节点选 1.28s、返回 1.15s、切页 1.85s、弹窗 1.6s、确认 1.6s、成功 2.05s；时长包含渐弱尾音，主体响应仍短促明确。
连续操作时，相关旧声音以 35ms 时间常数降到 28%，保留空间尾音；最多六个声部，超出时用 100ms 淡出替换。
Hover 停留 70ms 后触发，间隔至少 180ms；拖动与滚动保持安静。路由按钮只播放切页声，确认后紧接的切页让位于确认声。
总混音增益 0.5，主音量与音效音量相乘；音乐音量独立控制开场音；静音开关、音量滑杆与试听继续可用。入场时优先尝试自动启用声音；浏览器阻止时由首次点击或按键启用。
试听以 0.06s、1.4s、3.1s 为起点播放三种核心声音，保留尾音留白。页面隐藏时立即结束声音，不在返回时补播。
原始悬停素材信号过弱，保留来源但未用于可听声音，避免放大为噪声；最终声音参数与来源质量在 sound-spec.json 中记录。

开场音
home-music.js 与界面音效共享音频上下文，音量独立控制。当前只使用此前认可的 assets/audio/home-opening.wav；原 10s PCM 不变。淡出曲线采用两端速度与加速度均为零的 smootherstep，保留前段，避免末尾突然截断。
播放器只创建有限的一次播放源，明确 source.loop=false。末尾 3s（7–10s）以独立增益节点平滑渐弱至零，再释放播放源并进入 ended 状态，不接背景音乐，不会因普通点击、悬停、调节音量或恢复焦点而重启。
重播开场音与重播首页会主动解除预览暂停并重新播放开场。进入游戏会淡出尚未结束的开场；返回菜单仅续播未完成部分。一次访问完成后保持安静，新访问仍可播放一次。
自然结束的渐出使用独立增益节点和音频上下文时间调度；普通 UI 更新、音量调整、暂停恢复不会取消渐出。从尾部重新打开时继续剩余包络，不抬回完整音量。
主音量与音乐音量相乘，开场混音增益 0.24；界面音效控制和音量仍独立。当前运行资源和交付包中已移除所有后续循环，旧音频仅归档在工作目录。
入场前预取并解码开场音，主动尝试浏览器允许的有声自动播放；在页面入场调用前启动一次开场音。权限判断最多等待 120ms，已获准后的解码最多等待 1000ms，避免卡住页面。浏览器阻止自动播放时，首次真实点击或按键重新请求恢复音频；不绕过浏览器权限，不在后台自动启动。
章节点选
ui-chapter.wav 从现有 ui-hover.wav 的空间尾音提取，避开前 85ms 的直接起音；保留原音高和泛音，不新增噪声、音符或音高变化。75ms 平滑起音，2kHz 低通，1.28s 自然尾音，PCM 峰值 0.145。
章节点选音量 0.62，同一章重复点击为 0.38；章节 Hover 降为 0.48。选择时 Hover 尾音以 90ms 时间常数缓降至 60%，相邻选择尾音以 110ms 时间常数降至 20%，不再在按下时切断 Hover。点选间隔至少 220ms，快速点击仍立即更新画面；拖动与滚动不触发选择音。
语言选择和超时选择继续使用原 ui-select.wav；开场音及其他页面声音保持原配置。

预览暂停与恢复
共享音频出口在失焦、网页隐藏或 pagehide 时立即关闭，并暂停音频上下文；焦点恢复后继续同一播放源，不重新播放开场。异步解码和恢复也受同一活动状态约束，避免后台晚启动。
未完成的开场每秒保存一次检查点，在暂停、关闭时立即保存。重新打开同一版本，允许自动播放时自动续播剩余部分，浏览器拦截时首次点击后续播；完成后不再接循环，同一次访问保持安静；主动重播开场会清零。以 BroadcastChannel 限定当前操作的预览出声。
预览导航增加暂停声音 / 继续声音。标准页面生命周期与恢复逻辑已验证；Codex 仅收起面板时，实测工具并未改变网页焦点或隐藏状态，不能把这个宿主操作宣称为已通过自动暂停。该场景需关闭预览标签或使用暂停声音。

全局声音开关
首页与封面页右上角新增扬声器按钮，位于设置左侧，沿用现有 Hover、按下反馈与从右向左逐个入场。关闭时扬声器显示叉号。
开关控制共享输出：开场音和全部九种操作音效立即静音，音频上下文同时暂停；在章节、设置、游戏内与重播期间也不触发声音。开启后恢复原音量，尚未结束的开场接着播放，已结束的开场不会因开启而自动重播。
设置页与预览中的声音开关、游戏内扬声器使用同一状态。选择保存在本机，刷新或重新打开后继续生效；关闭状态下不尝试自动播放。首次点击关闭时不会先解锁开场，也不播放关闭确认音。
