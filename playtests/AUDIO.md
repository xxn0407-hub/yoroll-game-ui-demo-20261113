# 玩法声音规范

版本：`ethereal-gameplay-20261116`。18 个本地 PCM 文件，含 17 个事件音与一个 12 秒图音示例。使用已经确认的 Yoroll 音色重新剪辑、降低音高、滤去刺耳高频，并添加连续渐入／渐出。没有引用旧 test 链接中的操作音、视频音轨或 WAV，也没有新增鼓点、循环音乐、延迟回声或混响。

主界面原有的 `assets/audio/` 文件保持不变。新文件位于 `playtests/assets/audio/`，`manifest.json` 记录每个来源的 SHA-256、取样时间、处理参数、时长、峰值和 RMS。重建命令：`python3 tools/build-gameplay-audio.py`，需要 ffmpeg。

| 反馈 | 声音处理与触发 |
|---|---|
| 进入玩法 | 开场共鸣的轻柔尾部，只在开始时播放一次 |
| 选项 hover | 降低的轻共鸣；密集棋盘、日历和节奏目标取消扫过即响 |
| 点击、连点 | 短、轻、无明确音阶；每 100ms 最多一次 |
| 长按、平衡、窥探 | 按下／松开分别反馈，不按住循环发声 |
| 滑动、连续擦除 | 完成有效手势时轻扫；无效方向给低声反馈 |
| 描摹、擦除揭示 | 开始操作与重要揭示节点反馈，不逐帧叠音 |
| 洞察、调查、支线 | 发现用轻共鸣，切换视界和回看用低柔过渡 |
| 语音口令 | 启用麦克风轻点，答案不符用低柔反馈，不对每个识别片段发声 |
| 日历、记忆 | 普通日期轻点，记忆揭示用稍长的自然尾音 |
| 道具、配方、关联照片 | 选择／取用材料与合成分层，错误配方用低柔提示 |
| 转盘、拼图、数独、棋类、收纳 | 选择与落位区分，取消密集网格的 hover 叠音 |
| 射击、追击、赛车、篮球、台球 | 输入与命中／结果分开，赛车不新增引擎轰鸣循环 |
| 节奏交互各类型 | 短、无明确音高的触感；错过更轻、更低，避免键盘式音阶 |
| 成功 | 与开场同源、略明亮的温暖共鸣，连续衰减 |
| 失败／不可用 | 更低、更暗、更轻；不使用刺耳警报或重击 |
| 图音示例 | 新制单次尾音后保持安静，完整保留 12 秒图片切换时序 |

所有事件都进入同一 SFX 总线，沿用 0.5 的总增益。快速操作之间设有全局 75ms 间隔和各自限流，播放上限沿用主音频层的 6 个声音；新动作会降低旧动作的尾部，不累积成和弦。结算声音压低动作尾部，正常推进到下一节点时保留其自然尾音，避免再叠一声入场重音。离开目录、暂停、静音、失焦或关闭预览会停止正在播放的声音。

参考视频设置 `reference-silent`，图音替代素材设置 `theme-media` 并接入同一 Web Audio 输出。开启总开关也不会解禁参考视频。原始 JSON 仅保留逻辑和时序基线，保持字节一致；原音频地址不会用于图音节点的播放。

独立 Unity 和跨域网页游戏不在此仓库中。新版适配器要求关闭旧音频并回传声音事件，详见 [INTEGRATION.md](INTEGRATION.md)。此处完成的是网页预览及宿主路由；原引擎内部的音频替换需要接入方实现该协议。
