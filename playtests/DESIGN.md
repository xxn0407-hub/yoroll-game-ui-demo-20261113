# 玩法视觉与动效调整

延续已确认的游戏界面，以 1920×1080 为比例基准，按视口较短的缩放关系统一缩放。背景 cover 铺满视口；有归一化坐标的目标使用原 16:9 空间，周围用同画面的模糊暗色延展，避免改变目标与画面的对应位置。

| 内容 | 新版处理 |
|---|---|
| 分类入口 | 9 类侧栏，右侧卡片目录；单项体验和连续体验分开 |
| 主标题／玩法标题 | 30／27 设计像素，轻字重，控制字距 |
| 正文／辅助信息 | 18／14–16 设计像素，不把调试信息混入玩家操作区 |
| 操作按钮 | 46–53 高，沿用胶囊轮廓与柔和玻璃光感 |
| 目标点击与长按 | 细光环与局部进度，成功时光圈舒展消散 |
| 滑动与描摹 | 方向提示保持稳定，轨迹即时反馈，判定后柔和收尾 |
| 场景调查 | 轻量菱形标记、阴阳切换、相簿和笔记分层呈现 |
| 道具与合成 | 材料、配方槽和产物有明确层级，操作后同步库存 |
| 棋类与竞技 | 弱化装饰性容器，保留清晰棋盘／场景；状态由引擎回传 |
| 节奏交互 | 每个目标独立收圈与判定，支持点击、连点、长按、滑动和对抗 |
| 视频控制 | 紧凑底栏，倍速菜单复用已确认的选中光感和开合节奏 |
| toast／确认弹窗 | 沿用现有材料展开、文字后出现、文字先退场再收拢的顺序 |

入场主要使用 640ms 的柔和减速与 32ms 错峰，上限 220ms，避免多层信息同时抢入。菜单为 280ms 展开、180ms 收拢。操作成功反馈为局部光圈，失败使用轻微色调变化和低调提示，不添加强闪光。浮尘放在内容后方，缓慢漂浮，保留远近层次。遵循系统减少动态效果设置。

源规则不因视觉改版而修改。网页版实现和原引擎接口的边界，以及尚需业务联调的部分，见 [INTEGRATION.md](INTEGRATION.md)。
